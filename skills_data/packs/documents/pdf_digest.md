# PDF Digest

## Output sections
- Document identity (filename, approx pages)
- Executive summary (≤150 words)
- Key entities
- Key dates
- Claims list with locators
- Open questions / missing pages

Mark extracted text quality issues (OCR noise, truncation) explicitly.

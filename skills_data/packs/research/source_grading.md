# Source Grading

## Grades
- **A** Primary contemporaneous record (official filing, raw log, verified tool output)
- **B** Secondary reporting with clear provenance
- **C** Opinion, anonymous, or single-source narrative
- **D** Anonymous rumor / unverifiable social post
- **X** Agent self-statement (not external evidence)

## Process
1. Identify the claim.
2. List each supporting source with grade.
3. Note independence (same pipeline vs independent).
4. Only A/B sources should move Bayesian posteriors without extra caution.

# Contradiction Scan

1. Normalize claims to subject-predicate-object form where possible.
2. Group by subject/topic.
3. Flag pairs that cannot both be true.
4. For each conflict: sources, dates, source grades, suggested resolution path (need more evidence / prefer higher grade / mark disputed).

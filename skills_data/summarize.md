# Summarize Skill

When asked to summarize:

1. Identify the main claim or outcome.
2. List the critical supporting evidence (prefer external observations over agent statements).
3. Note any uncertainty or conflicting evidence.
4. Keep the summary under 120 words unless the user requests more detail.

Never invent facts. Prefer interventional evidence (environment results, tool outputs, verified outcomes) over the agent's own prior statements.
